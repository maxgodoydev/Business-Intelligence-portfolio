# Melhorias futuras do portfólio

Este documento reúne melhorias planejadas para a evolução do portfólio de projetos em Dados, Analytics e Business Intelligence.

## Melhorias planejadas

- **Documentação:** aprimorar os arquivos README para apresentar objetivos, tecnologias utilizadas, etapas de desenvolvimento e resultados de cada projeto.
- **Visualização de dados:** adicionar capturas de tela dos dashboards e exemplos de análises realizadas, facilitando a compreensão dos resultados.
- **Organização dos projetos:** padronizar a estrutura de pastas e os nomes dos arquivos para facilitar a navegação e a manutenção dos repositórios.
- **Qualidade dos dados:** documentar etapas de limpeza, transformação e validação dos dados utilizados nas análises.
- **Novos projetos:** desenvolver estudos práticos que envolvam SQL, Python, Power BI e análise de indicadores de negócio.

## Objetivo

Evoluir continuamente o portfólio, tornando os projetos mais claros, organizados e úteis para demonstrar conhecimentos técnicos e capacidade de resolver problemas com dados.
