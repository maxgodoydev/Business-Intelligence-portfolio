# Organização dos projetos

A organização dos arquivos facilita a leitura, a manutenção e a apresentação dos projetos de análise de dados.

## Estrutura sugerida

- `README.md`: apresentação do projeto, objetivos e instruções.
- `data/`: arquivos de dados utilizados, respeitando as regras de privacidade e compartilhamento.
- `scripts/`: códigos de consulta, tratamento e análise dos dados.
- `reports/`: relatórios, dashboards exportados e resultados.
- `docs/`: documentação complementar do projeto.

## Boas práticas

- Utilizar nomes de arquivos claros e consistentes.
- Documentar as principais etapas de tratamento dos dados.
- Separar os arquivos conforme sua finalidade.
- Evitar publicar senhas, credenciais ou dados pessoais.

## Objetivo

Manter os projetos organizados, compreensíveis e fáceis de atualizar, facilitando a colaboração e a análise dos resultados.
